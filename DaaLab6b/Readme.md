# DAA Lab 6 – Dynamic Programming

## 📌 About the Lab

This lab focuses on solving problems using **Dynamic Programming (DP)**.

Dynamic Programming is an algorithmic technique that breaks a complex problem into smaller subproblems, solves each subproblem once, and stores its result for future use.

The main concepts covered in this lab are:
- Fibonacci Series
- 0/1 Knapsack Problem
- Longest Common Subsequence (LCS)
- Matrix Chain Multiplication

All programs are implemented using the **C programming language**.

---

## 📝 List of Problems

### Q1. Fibonacci Number Using Dynamic Programming

**Concepts Used:** Dynamic Programming, Array, Iteration

**Description:**

Write a C program to find the nth Fibonacci number using Dynamic Programming.

The Fibonacci series is generated by adding the previous two numbers.

**Formula:**

```text
F(n) = F(n-1) + F(n-2)
```

**Sample Input:**

```text
Enter the value of n: 7
```

**Sample Output:**

```text
Fibonacci number at position 7 = 13
```

**Complexity Analysis:**
- Time Complexity: O(n)
- Space Complexity: O(n)

---

### Q2. 0/1 Knapsack Problem Using Dynamic Programming

**Concepts Used:** Dynamic Programming, Arrays, Optimization

**Description:**

Given a set of items with their weights and profits, and a knapsack with a fixed capacity, find the maximum profit that can be obtained without exceeding the capacity.

Each item can either be selected once or not selected at all.

**Sample Input:**

```text
Number of items: 4

Weights:
2 1 3 2

Profits:
12 10 20 15

Knapsack capacity: 5
```

**Sample Output:**

```text
Maximum Profit = 37
```

**Complexity Analysis:**
- Time Complexity: O(n × W)
- Space Complexity: O(n × W)

Where:
- n = Number of items
- W = Knapsack capacity

---

### Q3. Longest Common Subsequence (LCS)

**Concepts Used:** Dynamic Programming, Strings, DP Table

**Description:**

Given two strings, find the length of their Longest Common Subsequence and display the actual subsequence.

A subsequence contains characters in the same relative order, but the characters do not need to be consecutive.

**Sample Input:**

```text
Enter first string: ABCDGH
Enter second string: AEDFHR
```

**Sample Output:**

```text
Length of LCS = 3
Longest Common Subsequence = ADH
```

**Complexity Analysis:**
- Time Complexity: O(m × n)
- Space Complexity: O(m × n)

Where:
- m = Length of first string
- n = Length of second string

---

### Q4. Matrix Chain Multiplication Using Dynamic Programming

**Concepts Used:** Dynamic Programming, Matrix Multiplication, Optimization

**Description:**

Write a C program to find the minimum number of scalar multiplications required to multiply a complete chain of matrices.

The objective is to find the most efficient order of multiplication without changing the order of the matrices.

**Sample Input:**

```text
Enter number of dimensions: 4

Enter the dimensions:
10 30 5 60
```

**Sample Output:**

```text
Minimum number of scalar multiplications = 4500
```

**Complexity Analysis:**
- Time Complexity: O(N³)
- Space Complexity: O(N²)

Where N is the number of dimensions in the array. The number of matrices is N - 1.
